# Full-Stack AI Learning Roadmap

A complete curriculum for going from vibe-coding AI apps to understanding the entire stack — what models are, how they're trained, how they're made fast, how they're served from data centers, and the wider AI landscape beyond LLMs.

## Contents

| File | What it is |
|---|---|

| **[RESOURCES.md](RESOURCES.md)** | The library: ~170 curated, link-verified resources across 21 sections. |
| **[roadmap.html](roadmap.html)** | Interactive tracker: open locally in any browser — 132 checkable tasks with progress saved in localStorage, every resource one click away. |

## How this was built

Researched and assembled with Claude (Aug 2026): parallel research agents gathered and link-verified resources per stack layer, then the plan went through four rounds of adversarial review — schedule realism, data/eval discipline, production coverage, and frontier currency — with every factual claim independently verified.

## Keeping it current

The roadmap uses a **pre-phase audit protocol** (rule 8 in ROADMAP.md): before starting any phase, its section gets re-audited — links verified, availability re-checked, genuinely-new material added. Fast-moving sections (AI engineering, inference, vision, robotics) get full audits; stable foundations (math, backprop, Karpathy) don't need them. Last full revision: **August 2026**.

## The one-sentence version

Watch/read → then build. Core > Survey > Reference. Projects > completion. Start with [Karpathy's 1-hour intro](https://www.youtube.com/watch?v=zjkBMFhNj_g) — that's Day 1.
